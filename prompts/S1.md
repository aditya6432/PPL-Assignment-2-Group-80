### Review Result

The print-all-traversals function and its helper functions were reviewed.

Results:

- Preorder traversal visits root, left subtree, then right subtree.
- Postorder traversal visits left subtree, right subtree, then root.
- Empty trees produce three empty lists.
- Single-node trees produce the same one-element list three times.
- Balanced and unbalanced trees produce the expected traversals.
- my-append correctly combines traversal lists.
- Each traversal is printed on a separate line.
- The existing S1 test script passed.
- The implementation assumes well-formed binary trees.
